# Свадебный сайт: Илья & Юлия

Обычный сайт из HTML, CSS и JavaScript. Без сборки и серверов, открывается двойным щелчком по `index.html`.

## Структура

```
wedding-site/
├── index.html        разметка (трогать не нужно)
├── css/style.css     оформление (цвета в самом начале файла)
├── js/
│   ├── config.js     ВСЕ ВАШИ ДАННЫЕ И ТЕКСТЫ
│   └── main.js       логика (трогать не нужно)
├── images/           фотографии
├── audio/            сюда положить music.mp3
├── favicon.svg       значок во вкладке
└── README.md
```

## 1. Где менять данные

Всё в **`js/config.js`**: имена, дата, место, цитата, программа, дресс-код, вопросы анкеты, ссылка на Telegram. Меняйте только текст внутри кавычек.

Пока в блоке стоит заглушка (`[ТЕКСТ]`) или поле пустое, блок на сайте скрыт. Заполнили, и он появился сам. Чтобы увидеть все блоки с заглушками, поставьте `hideUnfilled: false`.

**Пока не заполнено:**

| Что | Где в config.js |
|---|---|
| Текст приветствия | `welcome.text` |
| История | `story.text` |
| Программа дня | `program.items` (время и событие) |
| Описание дресс-кода | `dressCode.text` |
| Короткая фраза под именами | `tagline` (необязательно) |

Календарь, таймер и кнопка «Построить маршрут» считаются сами из даты и адреса.

## 2. Фотографии

Файлы лежат в `images/`. Чтобы заменить фото, сохраните новое под тем же именем.

| Файл | Где используется |
|---|---|
| `hero.jpg` | главный экран (вертикальное, лица в верхней половине) |
| `photo-1.jpg`, `photo-2.jpg` | фотогалерея |
| `calendar.jpg` | фон календаря |
| `splash.jpg` | фон заставки и таймера |
| `og-image.jpg` | превью ссылки в мессенджерах (1200×630) |

**Больше фото в галерее.** Положите файлы, например `photo-3.jpg`, и добавьте строки в `gallery.photos` в `config.js`. Лучше всего выглядит 2, 4 или 6 фото. Размер: около 1200 px по длинной стороне, до 500 КБ на файл.

## 3. Музыка

1. Положите файл в `audio/` с именем **`music.mp3`** (до 5 МБ).
2. Всё. На сайте появится круглая кнопка Play/Pause.

Музыка включается после нажатия гостя на заставку: браузеры запрещают автозапуск звука без действия пользователя. Если файла нет, кнопки нет.

## 4. Как подключить отправку анкеты

**Сейчас анкета в демо-режиме: ответы никуда не уходят, и гость видит об этом честное сообщение.** Чтобы ответы приходили к вам, нужен внешний сервис. Есть два простых варианта.

### Вариант А. Formspree (ответы на почту, 5 минут)

1. Зарегистрируйтесь на formspree.io и нажмите **New Form**.
2. Скопируйте адрес вида `https://formspree.io/f/abcdwxyz`.
3. В `config.js` в блоке `rsvp` впишите:
   ```js
   type: "formspree",
   endpoint: "https://formspree.io/f/abcdwxyz",
   ```
4. Заполните форму на своём сайте и проверьте, что письмо пришло.

Бесплатный тариф ограничен по числу ответов в месяц. Актуальные лимиты смотрите на сайте сервиса.

### Вариант Б. Google Таблица (все ответы в одной таблице)

1. Создайте таблицу в Google Sheets. В первой строке напишите: `Дата | Имя | Придёт | Напитки | Комментарий`.
2. **Расширения → Apps Script**. Удалите всё и вставьте:
   ```js
   function doPost(e) {
     var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
     var p = e.parameter;
     sheet.appendRow([new Date(), p.name, p.attend, p.drinks || '', p.comment || '']);
     return ContentService.createTextOutput('ok');
   }
   ```
3. **Начать развёртывание → Новое развёртывание → Веб-приложение**. Выполнять от имени: **я**. Доступ: **у всех**. Скопируйте адрес веб-приложения.
4. В `config.js`:
   ```js
   type: "googleSheets",
   endpoint: "https://script.google.com/macros/s/ВАШ_АДРЕС/exec",
   ```
5. **Обязательно отправьте тестовый ответ и проверьте таблицу.** Google не даёт сайту прочитать ответ сервера, поэтому сайт знает только, что запрос ушёл, а не что строка записалась.

### Про Telegram-бота

Нельзя вставлять токен бота прямо в код сайта: он виден любому, кто откроет страницу, и бота могут украсть. Если хочется уведомления в Telegram, подключите Formspree или Google Таблицу, а уведомление настройте на их стороне.

## 5. Как выложить сайт на GitHub Pages

1. Зарегистрируйтесь на github.com.
2. Нажмите **New repository**, придумайте имя (например `wedding`), поставьте **Public**, нажмите **Create repository**.
3. Нажмите **uploading an existing file**. Перетащите **содержимое** папки `wedding-site` (папки `css`, `js`, `images`, `audio` и файлы `index.html`, `favicon.svg`). Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В разделе Source выберите **Deploy from a branch**, ветку **main**, папку **/ (root)**, затем **Save**.
5. Через 1–2 минуты адрес сайта появится вверху страницы: `https://ВАШ-ЛОГИН.github.io/wedding/`.
6. **Превью ссылки.** В `index.html` найдите две строки с `ВАШ-ЛОГИН.github.io/ВАШ-РЕПОЗИТОРИЙ` (теги `og:image` и `og:url`) и замените на ваш реальный адрес. Иначе в Telegram и WhatsApp ссылка будет без картинки.
7. Изменили файл на GitHub, подождите около минуты и обновите страницу.

Репозиторий публичный, поэтому фото и адрес видны всем, у кого есть ссылка. В `index.html` стоит `noindex`, чтобы сайт не попадал в поиск. Если хотите, чтобы его находили, удалите эту строку.

## 6. Если что-то не так

- **Белая страница или нет заставки.** Откройте консоль браузера (F12) и пришлите текст ошибки.
- **Фото не заменилось.** Проверьте точное имя файла (регистр важен: `hero.jpg`, а не `Hero.JPG`) и обновите страницу с очисткой кэша (Ctrl+Shift+R).
- **Таймер показывает не то время.** Проверьте `dateISO` в `config.js`: формат `2026-11-14T10:00:00+03:00`.
